# Gemini Character Reference Image Prompts

Repository: https://github.com/amritpap2026-cell/Coomedy-ever

## Important workflow
1. Generate ONE character at a time. Never put multiple different characters in one image.
2. First generate that character's identity master sheet. Save the best clean front-facing portrait as the identity reference.
3. For every later angle or outfit generation, upload that exact master portrait to Gemini as an image reference and say to preserve the same person. Do not rely on text alone for face consistency.
4. Generate one outfit sheet per character, then additional pose/angle sheets using the same reference portrait.
5. Do not use AI-generated text labels inside images; add labels later in a design tool if needed.
6. Review every panel. If face, hair, age, distinguishing marks, outfit details or anatomy drift, regenerate that sheet.
7. Keep children age-appropriate and preserve their starting ages unless the story timeline advances.

## Universal quality and consistency instructions
Photorealistic cinematic Nepali slice-of-life character photography. Realistic Nepali facial features, natural skin texture and pores, believable anatomy and proportions, realistic hands with five fingers, natural fabric folds and stitching, accurate garment construction, soft Himalayan morning daylight, neutral uncluttered studio/balcony background, high detail, sharp focus. The character must remain exactly the same individual in every panel: identical face shape, eye spacing, nose, lips, skin tone, hairstyle, hairline, age, body build and distinctive marks. No face blending, no duplicate people, no redesign, no random accessories, no text, no watermark, no logos unless specified. Each panel must show the full intended pose clearly without cropping important body parts.

## How to create the identity master sheet
Paste the character's full prompt below into Gemini. Generate a clean 4×4 contact sheet (16 panels), all panels showing the SAME single character:
- Row 1: front full-face close-up; front head-and-shoulders; 45-degree left close-up; 45-degree right close-up.
- Row 2: exact left profile; exact right profile; back of head showing hairstyle; three-quarter back view.
- Row 3: full-body standing front; full-body standing 45-degree left; full-body standing 45-degree right; full-body standing back.
- Row 4: seated naturally on a chair; seated holding a ceramic coffee cup; walking naturally; relaxed standing with hands visible.
Keep the character's signature outfit identical in all 16 panels. Use consistent camera distance and neutral lighting. Clean evenly spaced panels, no borders with text, no captions, no panel numbers. This is a reference contact sheet, not a collage of different people.

## How to create the seven-outfit wardrobe sheet
Upload the approved identity master portrait as a reference image. Ask Gemini for a 7-panel wardrobe contact sheet, one full-body panel per outfit listed for that character. Keep the exact same face, age, hairstyle, body proportions and distinguishing marks in every panel. Show head-to-toe clothing clearly, front-facing or slight ¾ angle, neutral standing pose, arms slightly away from torso so clothing silhouette is visible. Each outfit must match its written description exactly, including colors, layers, footwear and accessories. Do not invent extra outfits. No text labels, no logos, no cropped feet, no duplicate outfit. Use a 4×2 grid with the eighth cell left blank/neutral.

## How to create extra angle / expression sheets
Upload the approved identity master portrait and the relevant outfit reference. Generate a 4×4 sheet of the same character in the SAME selected outfit:
- front, ¾ left, ¾ right, exact left profile
- exact right profile, rear view, low camera angle, high camera angle
- neutral expression, joyful laugh, restrained smile, surprised
- thoughtful, mildly annoyed, genuinely sad (subtle), calm/deadpan punchline expression
Maintain exact identity and selected outfit. No exaggerated cartoon expressions.

## Suggested file naming
Use these names when uploading approved images:
- `studio/characters/references/<character_id>/identity-master.png`
- `studio/characters/references/<character_id>/wardrobe-7-outfits.png`
- `studio/characters/references/<character_id>/angles-expressions.png`

If GitHub mobile cannot upload large image files reliably, upload via the repository web interface or GitHub's Add file → Upload files. Keep the original full-resolution PNG/JPG; do not compress away facial detail.
