# Comedy Ever Studio

This directory contains the next-stage Nepali comedy studio workflow. The original Saturday script generator is preserved.

The target pipeline supports selectable Nepali character pairings, short 9:16 episodes (30–50 seconds), and long 16:9 episodes (1–2 minutes). Avatar video, Nepali voice synthesis, speaker-specific lip-sync and MP4 rendering will be integrated after provider selection.
